# Multi-panel drawer sidebar navigation

The sidebar component uses a multi-panel drawer pattern: Level 1 routes are always visible; clicking a Level 1 route opens a second panel to its right showing Level 2 routes; clicking Level 2 opens a third panel for Level 3. Each panel is `w-64`, equal width. Panels slide in from the left via CSS grid transitions (`grid-template-rows: 0fr → 1fr`). Clicking a new parent at any level closes all deeper panels. After a leaf node is clicked and navigation occurs, the drawer collapses back to Level 1. Active state is derived from `usePathname()` — leaf nodes highlight boldly, ancestor nodes highlight with reduced opacity. The sidebar does NOT auto-expand to show panels for the active route on direct URL navigation; the drawer starts collapsed at Level 1. The component is inline (not fixed-position) so it can be placed inside any layout. On mobile (below `md`), only the deepest open panel is visible at full width, creating a drill-down navigation pattern. Basic accessibility only (tab-focus, roles, `aria-expanded`).
