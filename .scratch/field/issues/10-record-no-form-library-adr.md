Type: grilling
Status: open

## Question

The map's standing preference is hand-rolled, no external form/component libraries — a trade-off offered twice during grilling and never confirmed as ADR-worthy. The multi-select work has since piled real machinery onto that choice: disclosure popup, focus choreography, live-region announcements ([Select presentation policies](01-select-presentation-policies.md), [Multi-select popup accessibility contract](06-multi-select-popup-a11y.md), [Closed face structure](09-closed-face-chip-buttons.md)).

Decide: does this effort record an ADR for the hand-rolled-no-form-library trade-off before the map closes? If yes, draft it (hard to reverse? surprising without context? a genuine trade-off? — all three currently look true). If no, record the reasoning here so the question stays closed.
